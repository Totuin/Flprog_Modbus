# Тесты Flprog_Modbus (host)

Запуск на Linux с GCC и Clang: `bash tests/host/run.sh` из корня библиотеки либо из любого каталога по полному пути.

Используются заглушки Arduino, flprogUtilites и UART; никакие устройства не открываются. Тестируются CRC, упаковка FC15, ответ FC1, проверка длин, таблицы, копирование и повторная настройка, RTU-буферы. Выполняется с ASan/UBSan для буферов 64 и 250 байт.

`test_all_headers.cpp` используется для проверки компиляции и линковки всех .cpp без исключений/RTTI со вспомогательной заглушкой TCP (`flprogEthernet.h`).

Этот набор **не заменяет** сборку настоящего проекта на STM32/AVR/ESP32 и проверку Modbus-приборов.
